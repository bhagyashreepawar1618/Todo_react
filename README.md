# 📝 To-Do List App (React + Context API)

A modern and interactive **To-Do List Application** built using **React.js** and **Context API** for state management.

This application allows users to efficiently manage daily tasks with features like adding, editing, deleting, and marking tasks as complete — all handled using centralized global state.

- 💾 Local Storage integration 
- 📱 Responsive design

---

## 🧠 State Management

This project uses **React Context API** to:

- Store all tasks globally
- Avoid prop drilling
- Manage add, edit, delete, and toggle functionality
- Keep UI in sync with state changes

## ⚙ Core Functionalities

### ➕ Add Task
- User enters task
- Task is added to global state
- UI updates instantly

### ✏ Edit Task
- Click edit button
- Modify task text
- State updates dynamically

### 🗑 Delete Task
- Removes task from global state
- UI re-renders automatically

### ✅ Mark as Complete
- Toggle completion status
- Applies strike-through styling
